# CodeQuest Privacy Statement

Effective October 29, 2026

CodeQuest is a free app for learning to code: https://ubuntu-apps.github.io/code-quest/. It has no accounts, no ads and nothing to buy, and it doesn't collect personal information from anyone, including children under 13.

## What CodeQuest stores, and where

Everything a learner does in CodeQuest is saved only in their own browser, on their own device:

- stages, challenges and gate quizzes completed, and code they have typed
- XP, streak, badges, rank and quiz review history
- settings such as theme and sounds
- the name a learner types on a certificate, if they make one

None of this is sent to us or to anyone else. Learners can delete it by clearing the site's data in their browser, and can move it to another device with the backup file on the Settings tab.

## Anonymous usage counts

To see which stages people reach and where they get stuck, CodeQuest sends anonymous counts to [GoatCounter](https://www.goatcounter.com), a privacy-friendly analytics service. Examples: a screen was opened, someone cleared the Variables gate (quiz), someone opened a hint for a challenge.

- No cookies, and no identifier for the learner or device.
- Nothing the learner types is sent: no code, answers or names.
- Any learner can turn counting off on the Settings tab, under Privacy.
- Counting doesn't happen when the app is offline or the counter is blocked.

[GoatCounter's website](https://www.goatcounter.com) describes what it receives and keeps.

## Other services the app uses

- The app is hosted on GitHub Pages. GitHub may log technical information such as IP addresses when the page is loaded; see [GitHub's privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).
- The code runner (Python and SQL) is downloaded from the jsDelivr content network the first time a learner runs code, and then kept on the device.
- "Send feedback" opens the learner's own email app with a message they can edit; we receive only what they choose to send.
- "Report a problem" opens a page on GitHub, which needs a GitHub account and is public.
- "Set a daily reminder" creates a calendar event only when a learner taps it: it opens Google Calendar with the event filled in, or downloads a calendar file for their own calendar app.

## Artificial intelligence

CodeQuest does not use artificial intelligence. No learner data, code, answers or usage information is sent to an AI service, used to train AI models, or analysed by AI. Challenges are checked by running the learner's code against fixed tests on their own device, and quizzes by comparing answers with fixed correct answers.

## How privacy is protected

- **No accounts and no personal information:** there is nothing to sign up for, so there are no names, email addresses, passwords or student records to protect.
- **Data stays on the device:** progress and code are stored only in the learner's browser, and the code runs there too, without being sent to a server.
- **Minimal, anonymous counting:** usage counts carry no cookies or identifiers, include nothing the learner types, and can be turned off.
- **No ads, tracking or selling of data:** CodeQuest has no advertising, no third-party trackers, and never sells or shares data.
- **Open source:** anyone can check what the app does in its public source code: https://github.com/ubuntu-apps/code-quest.

## Children and schools

CodeQuest doesn't ask for or collect names, email addresses or any other personal information, so learners of any age can use it without an account or parental consent. Schools don't need to share student data to use it.
